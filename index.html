Before you start

VocaPin runs on two free services: Supabase stores and syncs your words, and Gemini looks up meanings and example sentences. You connect both once. Each user can save up to 20,000 words.

  1. Sign up and get your keys Supabase access token · Gemini API key
  2. Put the keys into the app one-time setup in Settings
  3. How I study with VocaPin two ways to save words

1. Sign up and get your keys

1-1 · Supabase access token

  1. Sign up at supabase.com. The free plan is enough.
  2. Click New project. Enter a name and a database password, pick the region closest to you, and click Create new project. Wait about a minute until it is ready.
  3. Open Account > Access Tokens and click Generate new token. If you can pick an expiry, choose the shortest one.
  4. Copy the token. It starts with sbp_. You will paste it into the app in step 2.

This token can control your whole Supabase account. Paste it only into VocaPin, and delete it after setup (step 2 reminds you).

1-2 · Gemini API key

  1. Sign in to Google with a personal account such as a gmail.com address.
  2. Open Google AI Studio API keys. Accept the terms if this is your first visit.
  3. Click Create API key. Choose an existing Google Cloud project or let AI Studio create one.
  4. Copy the key. It starts with AIza. No credit card is needed for the free tier.
Seeing "you do not have access to AI Studio"? You are signed in with a work or school account, and your organization has turned AI Studio off. Switch to a personal Google account from the profile icon in the top right, or open the link in a private window and sign in there.

2. Put the keys into the app

Install the APK, open VocaPin, and go to the Settings tab.

2-1 · Supabase

  1. Tap Set up automatically with access token and paste the token from step 1-1.
  2. If you have several projects, pick the one you made for VocaPin, then confirm.
  3. The app creates its table and fills in the project URL and key by itself. Your words start syncing right away.
  4. Go back to Access Tokens and delete the token. The app has already discarded it and keeps working without it.
Prefer to set it up by hand?
  1. In your project, open SQL Editor, click New query, paste the SQL below, and click Run.
create table if not exists public.words (
  key         text primary key,
  word        text not null,
  lemma       text not null default '',
  phonetic    text not null default '',
  lang        text not null default 'English',
  meanings    jsonb not null default '[]'::jsonb,
  example     jsonb,
  gloss_m_idx int not null default 0,
  gloss_k_idx int not null default 0,
  stage       int not null default 1 check (stage between 1 and 3),
  saved_at    timestamptz not null,
  definition  text generated always as (meanings -> 0 -> 'trans' ->> 0) stored
);

alter table public.words enable row level security;

drop policy if exists "vocapin anon full access" on public.words;
create policy "vocapin anon full access"
  on public.words for all to anon
  using (true) with check (true);

grant select, insert, update, delete on public.words to anon;
  1. Open Project Settings > Data API. Copy the Project URL, and set Max rows to 20000.
  2. Open Project Settings > API Keys and copy the Publishable key. It starts with sb_publishable_. Never use the secret key.
  3. In VocaPin Settings, paste the URL and the key, and tap Test connection.

2-2 · Gemini

  1. Under Gemini API Key, paste the key from step 1-2.
  2. Tap Test connection. A green "Connected" means you are done.

On Android, Settings also lists three permissions that must be on so saving from other apps works on mobile data. Turn them all on.

3. How I study with VocaPin

You never type a word into VocaPin. Wherever you meet an English word, select it and tap voca-pin save in the text selection menu. These are the two ways I use every day.

Method 1 · Circle to Search

  1. While reading anything on your phone, long-press the home button or navigation bar to open Circle to Search.
  2. Tap the word you do not know. It appears in the search box.
  3. Add meaning after the word and search.
  4. In the results, long-press the word to select it, then tap voca-pin save in the selection menu. If you do not see it, tap ⋮ (more) first.

Circle to Search is available on Galaxy and Pixel phones. On other phones, search the word in Chrome instead and save from there.

Method 2 · Ask Gemini or ChatGPT

  1. Open Gemini or ChatGPT and ask about the word, for example what does "resilient" mean?
  2. In the answer, long-press the word to select it.
  3. Tap voca-pin save in the selection menu.

Either way, VocaPin looks the word up with Gemini in the background, saves it with its meaning and an example sentence, and shows a small toast. Review your words later in the Vocab tab with flashcards.
