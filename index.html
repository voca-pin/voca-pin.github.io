Step 1

Grab your keys

Two sign-ups, both free, no credit card. About five minutes.

🗄️ Supabase access token

  1. Sign up at supabase.com. Free plan is plenty.
  2. Tap New project. Name it, set a database password, pick the region closest to you. Wait a minute while it spins up.
  3. Open Account › Access Tokens and tap Generate new token. If it asks for an expiry, pick the shortest.
  4. Copy the token. It starts with sbp_. You'll paste it into the app in step 2.

This token can control your whole Supabase account. Paste it only into VocaPin, then delete it after setup (step 2 reminds you).

✨ Gemini API key

  1. Sign in to Google with a personal account (a gmail.com one).
  2. Open Google AI Studio › API keys. Accept the terms on first visit.
  3. Tap Create API key. Pick a project or let it make one.
  4. Copy the key. It starts with AIza.
"You do not have access to AI Studio"? You're on a work or school account and it's switched off there. Swap to a personal Google account from the profile icon, or open the link in a private window.
Step 2

Drop them in the app

Install the APK, open VocaPin, head to the Settings tab.

🗄️ Supabase

  1. Tap Set up automatically with access token and paste the sbp_ token.
  2. Got more than one project? Pick the one you made for VocaPin, then confirm.
  3. Done. The app builds its table and fills in the URL and key for you. Words start syncing right away.
  4. Now go back to Access Tokens and delete the token. The app already forgot it and keeps working without it.
Prefer to set it up by hand?
  1. In your project open SQL Editor › New query, paste this, tap Run.
create table if not exists public.words (
  key         text primary key,
  word        text not null,
  lemma       text not null default '',
  phonetic    text not null default '',
  lang        text not null default 'English',
  meanings    jsonb not null default '[]'::jsonb,
  example     jsonb,
  gloss_m_idx int not null default 0,
  gloss_k_idx int not null default 0,
  stage       int not null default 1 check (stage between 1 and 3),
  saved_at    timestamptz not null,
  definition  text generated always as (meanings -> 0 -> 'trans' ->> 0) stored
);

alter table public.words enable row level security;

drop policy if exists "vocapin anon full access" on public.words;
create policy "vocapin anon full access"
  on public.words for all to anon
  using (true) with check (true);

grant select, insert, update, delete on public.words to anon;
  1. Project Settings › Data API: copy the Project URL, set Max rows to 20000.
  2. Project Settings › API Keys: copy the Publishable key (sb_publishable_…). Never the secret one.
  3. In VocaPin Settings paste the URL and key, tap Test connection.

✨ Gemini

  1. Under Gemini API Key, paste the AIza key.
  2. Tap Test connection. Green "Connected" = you're done.

Settings also lists three Android permissions. Flip all three on, or saving from other apps fails on mobile data.

Step 3

How I actually study

You never type a word into VocaPin. Wherever you see one, select it and tap voca-pin save. Two moves I use every day:

⭕ Circle to Search

  1. Reading anything? Long-press the home button to open Circle to Search.
  2. Tap the word you don't know.
  3. Add meaning after it and search.
  4. In the results, long-press the word, tap voca-pin save. Don't see it? Tap ⋮ first.

Circle to Search lives on Galaxy and Pixel. Other phones: search the word in Chrome and save from there.

🤖 Ask Gemini or ChatGPT

  1. Ask about the word. what does "resilient" mean?
  2. Long-press the word in the answer.
  3. Tap voca-pin save.

Either way, VocaPin quietly asks Gemini for the meaning and an example sentence, saves it, and pops a tiny toast. Later, flip through your words as flashcards in the Vocab tab.
